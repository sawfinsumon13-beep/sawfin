HOSTINGER UPLOAD (3 STEPS)
--------------------------
1. Log in to Hostinger → hPanel → Files → File Manager

2. Open public_html and DELETE old site files if replacing a previous upload

3. Upload bavarian-engines-website.zip → Right-click → Extract
   After extract you should see directly inside public_html:
     index.html
     shop.html
     about.html
     css/
     js/
     images/
     favicon.ico
   (NOT inside an extra subfolder)

4. Visit your domain — open index.html as the homepage

5. Optional: edit js/seo-config.js and set your real domain URL
