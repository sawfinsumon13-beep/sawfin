# Lotline Wholesale

Static multi-page HTML website for a Dutch/European B2B wholesale liquidation pallet business — inspired by the structure and service model of similar European clearance outlets.

## Pages

- `index.html` — Home
- `winkel.html` — Shop / product catalogue
- `over-ons.html` — About
- `contact.html` — Contact + form
- `privacybeleid.html` — Privacy policy
- `algemene-voorwaarden.html` — Terms
- `leveringsvoorwaarden.html` — Delivery terms
- `juridische-disclaimer.html` — Legal disclaimer

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
